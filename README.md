# Site de casamento

Prévia estática e responsiva do site público de casamento, preparada para publicação no GitHub Pages.

## Conteúdo da prévia

- apresentação e contagem regressiva;
- história do casal;
- informações da cerimônia e recepção;
- demonstração da confirmação de presença;
- demonstração da lista de presentes;
- dúvidas frequentes.

Os nomes, textos, datas e endereços são fictícios e serão substituídos pelas informações reais na etapa de integração com o painel administrativo.

## Visualizar localmente

Abra o arquivo `index.html` no navegador ou use um servidor estático local.

## Publicação

O workflow em `.github/workflows/pages.yml` publica automaticamente o conteúdo da branch `main` no GitHub Pages.
